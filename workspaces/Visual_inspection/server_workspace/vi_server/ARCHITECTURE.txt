DATA FLOW EXAMPLE:
═════════════════

1. Jetson uploads gauge ROI image
   ↓
2. POST /api/v1/jobs
   • Validate image (JPEG/PNG, < 10MB)
   • Generate job_id: "550e8400-..."
   • Save: data/jobs/550e8400.../roi.jpg
   • Insert DB: status=QUEUED
   • Enqueue: job_id → Queue
   • Return: {"accepted": true, "job_id": "550e8400...", "status": "QUEUED"}
   ↓
3. Background Worker picks up job
   • Update DB: status=RUNNING
   • Load: data/jobs/550e8400.../roi.jpg
   • Route: object_type="gauge" → gauge_pipeline.py
   • Execute: run_gauge_pipeline("/path/to/roi.jpg")
   • Result: {"reading": "5.2", "confidence": 0.92, ...}
   • Update DB: status=DONE, result_json="{...}"
   ↓
4. Jetson polls GET /api/v1/jobs/550e8400...
   • Return: {"status": "DONE", "result_json": "{...}", ...}
   ↓
5. Jetson parses result and takes action


JOB STATUS TRANSITIONS:
═══════════════════════

RECEIVED  →  Initial creation (image saved, DB record created)
    ↓
QUEUED    →  In processing queue (waiting for worker)
    ↓
RUNNING   →  Worker processing (pipeline executing)
    ↓
DONE      →  Success (result_json populated)
    ↓
FAILED    →  Error (error_message populated)


CONFIGURATION:
═════════════

.env file controls:
• DATABASE_URL          - SQLite database path
• STORAGE_ROOT          - Job files directory
• SERVER_HOST           - Bind address (0.0.0.0 for LAN)
• SERVER_PORT           - Port (default 8000)
• ALLOWED_OBJECT_TYPES  - Valid object types
• MAX_QUEUE_SIZE        - Queue capacity
• LOG_LEVEL             - Logging verbosity
